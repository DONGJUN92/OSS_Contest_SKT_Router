## 2. 개선 후보 검증 결과 (2건 모두 데이터로 기각)

### 후보 1 — 최종 선택 규칙: 베이지안 사후 선택 (기각)
- 가설: argmax p_correct(v) 대신 사전확률 결합 사후 `q_m ∝ p̄_m·f(v|1)`로 선택 오류 감소
- 반사실 실험: **전 셀에서 품질 delta 0.0000** — 선택오류 자체가 0%라 개선 대상이 없음. 예리한 검증기 체제에서 현행 규칙이 이미 완벽. 현행 유지 (더 단순).

### 후보 2 — 페이싱 꼬리 개선 (기각)
- 관찰: irt/fast에서 λ가 클립 상한(×64) 도달 상태로 종료 → 후회가 꼬리에 집중되면 개선 여지
- 프로브: 후회 이벤트의 사분위 분포 = **5.39 / 4.19 / 5.19 / 3.82%** (균등), 생존 모드 중 발생 **0/93건** (생존 모드 쿼리 비중 0.5%)
- 판정: 후회는 시퀀스 전체에 균등 — **Lagrangian 배분의 구조적 잔차**. "지불 가능했던 상자"란 개별 쿼리 관점이고, 전 쿼리에 열어주면 예산 초과 — λ가 정확히 그 배급을 수행 중. 완전 예지(offline knapsack) 없이는 축소 불가에 가까움. 페이싱은 정상 동작 (클립 도달은 마지막 0.5% 구간의 정상적 생존 방어).

## 4. 종합 결론

합성 검증 체제에서 파이프라인은 **개선 포화 상태**다. 남은 갭(irt/fast 4.65%)은 예산 제약의
그림자가격 잔차 + 세계 천장으로, 정책 구조 개선으로는 축소가 어렵다는 것을 두 개의
반사실 실험으로 확인했다. **추가 시뮬레이션 개선 시도는 과적합 위험 대비 기대 이득이
없으므로 중단하고, 잔여 역량을 실데이터 준비(백로그 B1~B12)에 투입하는 것이 옳다.**
