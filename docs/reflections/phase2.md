## 전략적 판독 (효율성·안정성·독창성)

1. **Fast tier에서 λ-지수 단일호출이 cascade를 2~2.5배 압도** (0.50 vs 0.20 / 0.64 vs 0.33) — 저예산 승부처 가설 재확인. 예산 사용률 97~100%, 파산 없음.
2. **Balanced/specialist에서는 cascade(0.93)가 단일호출(0.74)을 역전** — 단일호출은 검증기 관측 후 승급이 불가능하기 때문. **순차 open→observe→re-index→stop(M2 Pandora)이 채워야 할 공백이 정확히 정량화됨.** Phase 3의 성공 기준: 모든 셀에서 단일호출 지수와 정적 cascade를 동시에 이길 것.
3. **신호는 이미 포화**: oracle-p(진짜 확률)와 학습 p̄의 라우팅 점수가 사실상 동일 — 예측기 개선의 한계효용은 소진됐고, 남은 이득은 전부 **의사결정 구조**(순차성·예산 페이싱)에 있다. Phase 3 우선순위를 정당화하는 가장 중요한 발견.
4. **심사 자료 확보**: `eval/results/icc_curves.png` — 적합 ICC가 생성기 곡선과 시각적으로 일치 (해석가능성 어필).
