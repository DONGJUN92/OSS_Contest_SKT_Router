## 신규성 서사 수정 (제출 문서에 반영할 것)

**기각된 주장**: "베이지안 재지수화가 성능 이득의 원천" — 세 조건(기본/약한 인코더/약한 검증기)에서 일관되게 이득 없음. 후보 모델이 수십 개이거나 ICC가 교차하는 체제에서는 유효할 수 있으나, 본 챌린지 체제(모델 ≤10개)에서는 주장 불가.

**대체·강화된 주장** (실증 근거 확보):
1. **Weitzman 지수 정책 + λ가 이득의 엔진** — 종합 점수 +27%(W-A), +23%(W-B), 저예산 tier 최대 3배. DP 대조로 최적성 검증 완료
2. **IRT 생성적 신념 = 약한 프로파일러 보험** — 인코더가 약할 때 판별식 신념은 붕괴(0.52±0.10)하지만 IRT 신념은 유지(0.61±0.02). 모집단 수준 곡선(a,b)이 쿼리 수준 불확실성을 지탱. 실데이터(텍스트 인코더의 낮은 예측력)에서 더 중요해질 성질
3. 잔여 신규성(예산 페이싱 결합, conformal 정지)은 Phase 4·5에서 입증 예정

## Phase 4로의 이월 사항

1. **premium 근소 열세 + 후반 파산(unans 21~66)**: 정적 λ가 지출 궤적을 제어하지 못함 — mirror descent 페이싱이 해결해야 할 잔여 격차 (balanced-specialist 동률 → 상회 전환 포함)
2. λ 튜닝이 fold·tier마다 리플레이 이분탐색(~20 리플레이) — 페이싱 도입 시 초기 λ₀ 웜스타트로 축소 가능
3. 파산 의미론은 여전히 zero_quality 가정 (Q6 대기)
