## 발견 → 수정 → 검증 사이클

### D14 — 오답 균등 분산이 투표를 만능화 (검증 기준·생성기 결함)
- 초기 World D에서 전 정책 0.9955 천장 — 오답이 4-way 균등이면 p>0.2에서 투표 포화가 1
- 수정: 집중 오답 옵션 `conc=0.6` (실제 LLM 오답은 한 곳에 몰림)

### PerModelNoise (모델별 검증기 보정) — 주 가설 기각, 기능 유지
- 가설(심판 편향 → 전역 보정 오염)은 기각: corr 0.9146 ≈ 0.9166 (잡음 수준)
- 로지스틱 보정이 편향을 이미 흡수. 실데이터 이질성 대비 플래그(기본 on)로 유지, 무회귀 확인

### D15 — 생존 모드의 두 결함 → 페이싱 v3
- 결함: ① 예비비를 전역 min으로 추정(로그정규 입력에서 낙관 편향 → 트리거 지연)
  ② 생존 λ가 λ0×64 상대값(λ0 작은 세계에서 무력)
- 수정: ① 쿼리별 최저비용 0.9 분위수 ② 절대 생존 λ = max(λ0×64, 1.2/c_min) — 예약지수
  전면 비양수화로 파산 구조 차단
- 검증: corr/fast 무응답 3.56→0.3%(품질 +1.1%p), crossing/balanced 1.1→0.3%

### R1 — 튜너 headroom (fold 간 비용 이질성 대응)
- 잔여 무응답(corr/balanced 1.7%)의 원인: λ0을 보정셋 예산 100%에 밀착 튜닝 →
  테스트 fold의 비용 구성이 조금만 달라도 초과
- 수정: 튜닝 목표 = 예산 × 0.97 (품질 곡선이 상단 평탄이므로 비용 ≈ 0)
- 검증: corr/balanced 0.9429→**0.9635** — cascade와 0.25%p 차 (std 0.0145 이내, 통계적 동률).
  기존 3세계 무회귀 (delta ≤ 0.001)

### ★ D7 정밀화 — θ 베이지안 갱신의 유효 체제 발견 (제출 핵심 소재)
- D7(Phase 3): 완만한 ICC 세계(A/B)에서 갱신 무효 — 3개 조건에서 일관 확인
- **본 실험(corr, 급경사 a≈3.8)**: fast에서 **update-on +3.15%p** (0.8854 vs 0.8539),
  **호출 22% 절감** (2.97 vs 3.81) — 실패 관측이 θ 사후를 급락시켜 무의미한 중간 승급을
  자동 스킵하는 예언된 메커니즘 그대로. balanced에서는 잡음(-0.6%p) — 예산 여유 시
  스킵 가치 소멸 (일관)
- **정제된 주장**: "베이지안 재지수는 저예산 × 중첩실패(고판별) 체제에서 유효(+3.2%p),
  완만한 체제에서 무해(0)" — 기본값 update-on의 정당성 최초 실증. 명시적 스킵
  휴리스틱은 불필요 판정 (신념 경로가 이미 수행)
