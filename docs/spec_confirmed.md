## 답변 없이 확정된 사실 (자체 검증으로 해소)

문의 발신 이후, **답변을 기다리지 않고 해소할 수 있는 항목을 모두 자체 검증했다.**
그 결과 어느 답변 조합에서도 제출이 막히지 않음을 확인했다.

| # | 자체 해소 내용 | 근거 |
|---|---|---|
| Q2 | 데이터에서 자동 판정(`samples_per_cell`). **No여도 서열 6/6 유지, 오히려 격차 확대** | `run_b56.py q2no`, phase11 |
| Q4 | 데이터에서 자동 판정(`quality_kind`). 이진·Beta·**GRM** 3족 전부 구현·검증 | `run_b4.py`, phase10 |
| Q5 | 문항당 예산 모드 구현·검증. **페이싱 효과 정확히 0** (R5 설계대로 무의미화) | `run_b5.py`, phase12 |
| Q6 | 관대한 규칙에서도 **서열 6/6 유지**(격차는 축소) | `run_b56.py b6`, phase11 |
| Q1 | 과금형이어도 1~2줄 수정 + λ 재튜닝. 인코더는 hashing 고정으로 대응 | 분기 결정표 Q1 |
| Q3 | `cost_mirror.py` 파일 1개 교체 지점으로 격리, 단위 테스트로 오차 0 검증 | `tests/test_cost_mirror.py` |
| Q7 | 정책은 tier별 독립 튜닝이라 자동 적응. 영향은 **보고 점수 표기**뿐 | 분기 결정표 Q7 |

**결론**: 답변은 점수의 절대값 보고와 미세 최적화에만 영향을 준다. 정책·코드 경로는
어느 분기에서도 준비돼 있다.
